# ArduFiyat Fiyat Yardımcısı

Chrome/Edge üzerinde geliştirici modunda yüklenebilir Manifest V3 uzantısıdır.

1. Tarayıcıda Uzantılar > Geliştirici modu açılır.
2. Paketlenmemiş öğe yükle ile bu klasör seçilir.
3. Popup içinden ArduFiyat site adresi ve istenirse API v2 anahtarı kaydedilir.
4. Elektronik ürün sayfalarında sayfa başlığı ArduFiyat `/api/v2/match` servisiyle eşleştirilir.

Uzantı otomatik satın alma yapmaz; yalnızca ArduFiyat karşılaştırma sayfasına yönlendirir.
